# vim-dizzy
Just one more useless vim plugin.
Shuffles the text in the current window after 5 seconds of inactivity and refreshes it every 100 ms.

Installation via VimPlug
Add this line between plug#begin() and plug#end() in your ~/.vimrc:
Plug 'alyoksi/vim-dizzy'
Run :PlugInstall, then restart Vim.
Usage
- :ShuffleOn enables the plugin.
- :ShuffleOff disables it.
